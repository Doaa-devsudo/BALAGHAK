# Person 4: n8n + integration (`notify.py`, n8n workflow)

## Your job
1. When a report is saved, send it to n8n, and n8n notifies **the right team** on Telegram
   (urgent ones also go to the supervisor).
2. You lead the **integration**: the final full-flow test and the demo setup.

- **Files you own:** `notify.py` + the n8n workflow (export it to `n8n/workflow.json`)
- **Branch:** `n8n`
- **You depend on:** nothing. You can test with fake reports.
- **Who depends on you:** Person 2's `save_report` tool calls `send_to_n8n`.

## Before you start
1. Setup in `docs/00_TEAM_WORKFLOW.md` → section 1.
2. `git checkout -b n8n`
3. Install Docker **or** Node.js (for `npx`).
4. Telegram on your phone.

## Steps

### 1. Run n8n (~10 min)
One of:
```bash
docker run -it --rm -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n
# or
npx n8n
```
Open http://localhost:5678 and create the owner account.
(The `-v n8n_data...` part keeps your workflow if the container stops.)

### 2. Telegram bot and groups (~20 min)
1. In Telegram, talk to **@BotFather** → `/newbot` → choose a name → copy the **bot token**.
2. Create 4 groups and add the bot to each:
   `فريق الطرق` · `فريق الرقابة الصحية` · `فريق النظافة` · `المشرف`
3. Send any message in each group.
4. Open `https://api.telegram.org/bot<TOKEN>/getUpdates` in the browser. Find each group's
   `"chat":{"id": -100...}` (negative number). Write the 4 IDs down.

**Plan B:** if Telegram is a problem, use Discord: one channel per team →
channel settings → Integrations → Webhooks → copy URL → n8n **Discord** node (webhook mode).

### 3. Build the workflow (~45 min)
New workflow named «بلاغك - إشعارات»:

```
Webhook ─┬─► Switch (department) ─┬─► Telegram: فريق الطرق
         │                        ├─► Telegram: فريق الرقابة الصحية
         │                        └─► Telegram: فريق النظافة
         └─► IF (priority = عاجلة) ──► Telegram: المشرف
```

**Webhook node**
- HTTP Method: `POST`, Path: `new-report`, Respond: `Immediately`.
- The report arrives under `body`, e.g. `{{ $json.body.department }}`.

**Switch node** (mode: Rules), 3 rules, each: string `{{ $json.body.department }}` *is equal to*:
- `الطرق والأرصفة` → output 0
- `صحة البيئة والمنشآت الغذائية` → output 1
- `النظافة العامة` → output 2

Copy the names from `storage.py`. One different character = no match.

**Telegram nodes** (Send Message), one per output:
- Credential: Telegram API → your bot token (create once, reuse).
- Chat ID: that team's group ID.
- Text:
  ```
  🔔 بلاغ جديد {{ $json.body.id }}
  القسم: {{ $json.body.department }}
  الأولوية: {{ $json.body.priority }}
  الموقع: {{ $json.body.neighborhood }} - {{ $json.body.street }}
  المنشأة: {{ $json.body.facility }}
  الوصف: {{ $json.body.text }}
  ```

**IF node** (second connection from the Webhook): `{{ $json.body.priority }}` is equal to `عاجلة`
→ true → Telegram node to the **المشرف** group, text starting with «🚨 بلاغ عاجل».

### 4. Test URL vs production URL (important)
- `.../webhook-test/new-report` works **only** while you clicked **"Listen for test event"** in the editor.
- `.../webhook/new-report` works **only** after you **activate** the workflow (toggle at the top).

Build with the test URL. When it works: activate, and put the **production** URL in `.env`:
```
N8N_WEBHOOK_URL=http://localhost:5678/webhook/new-report
```

### 5. Write `notify.py` (~15 min)
Replace the stub body:
- `load_dotenv()` and read `N8N_WEBHOOK_URL` with `os.getenv`.
- If the URL is empty: print a warning and return.
- `requests.post(url, json=report, timeout=5)` and `response.raise_for_status()`.
- Wrap everything in `try/except Exception as e:` → print a warning and return.
  **It must never raise.** If n8n is down, the report is still saved and the user still gets a ticket.

Test: `python notify.py` sends the fake report from the test block → check Telegram.
Then test each department and an urgent one (change the dict in the test block).
Also test with n8n stopped: it should print a warning, not crash.

### 6. Export the workflow
In n8n: workflow menu (⋯) → **Download** → save as `n8n/workflow.json` in the repo.
**Before committing**, open it and make sure no bot token is inside
(credentials are normally not exported, but check). This lets anyone import it.

## Done when
- A fake report for each department arrives in the right group.
- An urgent one also arrives in المشرف.
- With n8n stopped, `python notify.py` prints a warning and exits normally.

## Push and merge
```bash
git add notify.py n8n/workflow.json
git commit -m "n8n: notify teams via Telegram"
git push -u origin n8n
```
Pull Request into `main` at **Checkpoint 1** (~hour 3), together with `rag`. Tell Person 2.
